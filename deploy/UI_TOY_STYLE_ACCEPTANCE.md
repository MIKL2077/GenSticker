# 2026-10-18 前端风格与 AI 换批验收记录

本地开发实现，尚未发布生产版本或上传微信。透明Logo、最新配色、补充动效及开发者工具同步情况以 [最新补充记录](UI_MOTION_FINAL_ACCEPTANCE.md) 为准。本记录覆盖10月16日界面版本之后的改动。

## 用户最终确认的方向

保留当前 `frontend/src/static/logo.png` 的图案、字标和配色。主视觉中的其他表情角色已撤下，使用这份Logo做立体悬浮卡片，增加少量薄荷色、奶油黄色装饰。全站恢复上一版的奶油白、珊瑚橙、薄荷绿，保留新布局、展台和立体反馈。

首页和AI页的Logo会缓慢悬浮、轻微旋转，点击后弹性回弹；卡片的厚度、投影和轨道使用CSS实现，Logo图片本身未改动。底部入口、分类、模板卡片、制作面板、个人中心及收藏历史统一为暖色立体风格。只使用 transform/opacity 动画及单次点击回弹计时器，无WebGL、视频、第三方动效库或持续JS动画循环。页面隐藏时暂停主视觉动画，支持减少动态效果偏好。

## 首页排行榜

原来的普通列表替换为前三名高低错落展台，第一名居中，三个名次均可直接进入制作。名次取全局模板卡片的实际近7日热度，不随模板分类、探索排序或翻页改变；没有热度时显示等待参与的空状态，不编造热力和名次。排行缩略图继续使用有界缓存，当前可见模板与排行榜缩略图共同保护。

## 换一批

`POST /recommend/jobs` 接受 `previous_job_id` 和 `idempotency_key`。服务端校验原任务归属、终态及原照片有效期，派生新任务，复用原照片和版本匹配的主体/表情分析缓存。原任务和原结果保留。

先从当前批次链未使用过的兼容模板中选取，避开上一批。不足9个就生成实际数量；本轮全部用过后开始新一轮，仍避开紧邻上一批。若没有其他可用模板，给出明确提示，不复制结果凑数。候选模板的单图输入约束、主体兼容性、素材许可及同布局数量限制继续生效。

换批提交失败时保留当前结果和选中项，重试复用幂等标识；从最近记录打开旧任务也可换批，无须再次上传。原图超过24小时后禁用换批并提示重新选照片。切换账户后旧提交不会打开到新账户界面。删除一批结果时，不会删除仍被其他批次使用的原照片。

## 次数与成本

默认 `GENSTICKER_DAILY_LIMIT=0`、`GENSTICKER_GLOBAL_LIMIT=0`，表示取消个人和全站每日任务上限。额度接口返回 `unlimited=true`、`remaining=null`，前端显示不限次数；同时兼容运营明确配置的正数限额。保留身份认证、每用户1个活动任务、全局最多10个活动任务、照片尺寸限制与原有网络限速。每日最多12张上传的旧限制改成每分钟6张新照片的频率保护。

目前生成使用本地CPU上的U2NetP、FERPlus和模板合成，不调用收费大模型，不消耗大模型token。`paid_ai_enabled=false`，任务成本账本仍记录CPU时间和输出字节，金额为0。服务器、存储、带宽成本仍存在；这里的“不限次数”不代表无限并发。

部署须同时更新API、worker及前端。SQLite会自动创建 `job_variations` 表，不重建原有数据表。若服务器 `/etc/gensticker.env` 仍设置旧的3/100限额，需要将两个环境值改为0并重启API；仅更新代码默认值不会覆盖既有环境变量。旧版worker不了解换批排除信息，因此不可只更新API。
