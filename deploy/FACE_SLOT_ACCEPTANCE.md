## 当前功能

首页“新模板试用”进入，上传一张清晰单人正面照片，再生成。人物头部替换原狗头，枯花、抓花的爪子、西装、路灯和文字位置保留；文字继续可改。上传提示说明侧脸 / 遮挡不适合，检测不到或有多张明显人脸时明确报错并保留表单输入。

服务器本地 OpenCV 进行人脸检测、可选小角度眼部对齐、头部裁剪和 GrabCut 抠图，按模板局部清除旧头，再做黑白处理与软边融合。声明式 face 图层限定坐标、清除多边形、像素与羽化范围。不做身份识别，不发送人像给外部 AI。

该模板需要服务器，端侧配方接口明确 supported=false；原来一直 / 看扁两个 JPEG 静态模板仍可本机制作。缩略图保留原参考狗头，不宣称示例预览已经完成换脸。图片表情来自用户照片，不能保证复现原狗的表情；帽子、遮挡或背景对比弱时可能需要换更清晰的照片。

## Skill 交付

`skills/meme-to-template/SKILL.md` 分为人工审查拆解与自动采集，配有 `references/decomposition.md`、不含图片的已测试 brief JSON 和 `scripts/decompose.py`。已同步本机安装目录。

可复刻步骤：识别反应意图 → 区分固定道具 / 动作和编辑槽位 → 标出坐标、目标清除多边形、受保护区域与图层顺序 → 定义输入及文字样式 → 脚本验证 → 检查真实替换 → 在授权范围发布。源照片前景 alpha 和原头清除 mask 分开处理，避免旧毛发 / 双眼残留与灰色背景边缘。

脚本支持受审查的人脸 + 文字槽位；不泛称全网图片或全身动作都能可靠自动转换。用于另一个图片时必须重新分析与测量，不能复制狗图坐标。运行需要兼容 GenSticker Python 环境、Pillow / NumPy / OpenCV / Pydantic；运行文件与示例 brief 不包含验证人像。

脚本在隔离服务器环境实际执行过：原文字重建 MAE 5.21，固定背景像素误差 0，真实换脸后编辑遮罩外 JPEG 误差 0.094，face_slot_tested=true。自动门槛检查遮罩不覆盖受保护道具、默认重建和真实替换，数值检查之外仍需看图验收。
