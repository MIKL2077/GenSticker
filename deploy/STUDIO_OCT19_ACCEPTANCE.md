## 微信分享边界

普通小程序入口：点击“发给好友”直接打开好友选择，发送带成品预览的模板卡片；原图另有微信系统分享菜单入口。模板卡片不是原始图片消息。

真实聊天工具入口：在微信提供 `apiCategory=chatTool` 且客户端支持时，使用 `shareEmojiToGroup`，失败后尝试 `shareImageToGroup`，再回退到系统图片分享。没有伪造聊天工具上下文或修改后台资格。

未找到直接写入用户个人表情库的公开接口，提供“怎么收藏成微信表情”的保存及添加指引，不做无效的“一键入库”按钮。能力依据为 [微信官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)，实际分享和表情格式仍需真机验收。
