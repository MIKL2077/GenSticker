# GenSticker 上线页面恢复方案

恢复截图中的首页和个人页，并接通已经恢复的模板生成服务。用户可以直接制作表情包；浏览历史和收藏在未登录时保存在本机，登录后同步到个人账户。

## 截图所确定的功能

首页保留橙红渐变背景、白色 GenSticker 品牌卡、标题和副标题、四个模板分类、分类数量、三列模板网格、九张加载骨架、页数和底部页码。底部固定“首页”和“我的”两个入口，保留手机安全区域。

个人页采用浅色内容面板，显示头像入口、未登录状态和登录提示。“历史记录”指浏览过的模板，而不是已生成图片；“收藏模板”显示用户主动收藏的模板。

现有代码只有首页和生成弹窗，缺少个人页、底部导航、账户接口、收藏与浏览历史。品牌标识仍为默认占位样式，分页只有左右箭头，加载缺少完整骨架和失败重试入口。

## 完整交互

首页打开后加载分类和当前页缩略图，加载中显示九张骨架；失败显示重试，不无限停留在加载状态。分类切换回第一页；页码支持上一页、下一页和附近页数。卡片显示中文模板关键词，保留内部 key 供接口使用。

点击模板打开详情、写入浏览历史。详情按照模板规则要求图片和文字，支持收藏或取消收藏。生成期间禁用重复提交；成功后预览图片，支持保存相册和微信图片分享。接口限速或网络错误显示可理解的提示。

“我的”在游客状态下也允许浏览历史与收藏。历史去重并按最近浏览排序，最多 100 个模板，可清空。收藏最多 100 个模板，可取消。列表空时显示说明和“去首页”入口；失效模板明确提示，不阻塞整页。

点击头像执行微信登录，后端通过 code2Session 校验身份。只收集必要的账户标识，不默认索取微信昵称和头像。登录后显示账户状态；游客记录合并进账户。不同账户的本机缓存隔离，退出后切回游客缓存。网络失败的收藏与历史操作先保存在本机，重新连接后按操作顺序同步。

## 前后端接口

现有模板分类、详情、缩略图、JSON 生成接口继续使用。新增账户配置查询、微信登录、当前账户、退出登录、个人模板库查询、游客记录合并、收藏添加与删除、历史写入与清空。

账户数据使用 SQLite，放在服务专属可写目录。所有个人数据接口通过随机 Bearer Token 鉴权；数据库只保存 Token 哈希，登录会话七天过期，退出后撤销。查询和修改必须限定当前用户，不接收客户端指定的用户 ID。收藏与历史变更接口保持幂等，避免重试重复写入。

AppSecret 通过服务环境配置，不能打包到前端或提交 Git。凭据缺失时账户配置返回不可登录，按钮说明配置尚未完成；游客功能和生成继续可用。真实微信登录需要有效 AppSecret，测试使用隔离数据库和模拟微信提供方验证身份隔离与会话机制。

## 实施与提交

1. 恢复阶段：生成链路、缩略图、服务器隔离与防护，已通过真实微信文字、单图、多图和图文生成验证。
2. 设计阶段：保存本方案并更新部署说明，作为独立提交。
3. 后端阶段：账户、会话、收藏与历史，验证权限隔离、幂等和过期，再提交。
4. 前端阶段：恢复截图布局、个人页、列表与同步交互；编译并在微信模拟器验证，再提交。

每个阶段向 GitHub 工作分支 `codex/restore-wechat-final` 推送，保留主分支。当前本机账号没有仓库写权限，提交会先在本地保存，凭据恢复后按原顺序推送。

## 上线条件

后端为 `https://www.shangkun.uk/gensticker/api`，微信公众平台必须将 `https://www.shangkun.uk` 配为 request 合法域名。扫码真机和正式发布前验证域名、有效微信登录凭据、相册权限和隐私说明。服务器曾遭 root 入侵，当前止血与进程隔离不能替代可信系统重建；上线长期运营前需迁移到可信系统并更换暴露过的凭据。
