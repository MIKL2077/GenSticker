# 上传图片预览与编辑验收

2026-10-14，分支 `codex/restore-wechat-final`。图片编辑入口已实现，去背景预览接口已部署至公网 HTTPS API。模板数量仍为 295，其他项目服务未变。

## 当前交互

上传一张或多张图片后，自动打开暖色底部编辑面板；当前模板详情保留大图预览和“编辑图片”入口。编辑面板提供：

- 裁剪：方形、头像 4:5、横图 4:3、原比例；拖动图片调整位置，滑块缩放 1–3 倍。“应用裁剪”才提交，取消保留当前图片。
- 左右翻转、顺时针旋转 90°：在设备本地生成新 PNG，立即预览。
- 去背景 / 保留主体：点击才调用服务器本地 U2NetP，保留最大连通主体，以透明 PNG 预览；原透明图片复用 alpha。它不会自动挑选前景内部的人脸或移除帽子，仍可通过裁剪选取局部。
- 最近四步撤销、还原原图；多图独立保存记录，可切换编辑。完成后回到详情，使用当前编辑后的文件生成表情包。

处理中禁用重复操作和生成；关闭可放弃未完成操作，迟到结果清理，不覆盖新输入。错误保留当前图片与原图。格纹仅用于显示透明区域，不写进图片。用户未去背景时直接使用原图，旧版生成阶段主体开关已从当前页面移除；后端兼容旧参数。

## 资源与接口

本地编辑最多解码 400 万像素，输出最长边 1280，透明 PNG 保持 alpha；超大 JPEG 会先缩小。动画或当前不支持的格式会提示改用静态 JPG / PNG，原输入仍保留。编辑只清理自身创建的文件和 Blob URL，保留原相册文件，结束表单 / 离开页面清理编辑资源；启动清理此前会话留下的编辑器文件。

`POST /images/subject` 接收 `{"image":"Base64"}`，输入上限 4 MB，输出 `image/png`、`Cache-Control: private, no-store`。与手动生成共享两并发槽和按访问身份隔离的短期内存缓存；不落盘、不公开照片。Nginx 使用原生成限速区（6 次 / 分钟、burst 3）。模型只在自有服务器本地运行，不调用付费照片 API。

微信小程序固定使用 `https://www.shangkun.uk/gensticker/api`；H5 本地相对代理和环境变量不能覆盖微信包。使用故意指向 localhost 的构建变量验证过，导出的 `API_BASE_URL` 仍为公网 HTTPS。公网 `/healthz` 返回 HTTP 200、295 个模板。微信后台服务器域名配置页的访问被浏览器安全策略阻止，未读取或修改那一配置；最终真机网络与平台域名配置仍需扫码验收。
