## GitHub 交接

整改在 `codex/restore-wechat-final` 开发分支，不覆盖默认分支。核对远端提交、实际 CI 和发布标签，再通过维护流程合入。配置了 CI 不等于已在 GitHub 成功执行；安全门禁不能因已知依赖问题而静默关闭。真实模型、微信工具与共享服务器探针不在无密钥 hosted runner 自动执行。

正式交接还需明确运维权限、私密联系人、备份和密钥位置、外部告警接收人、未关闭风险与责任人。私有资料不能进入公开 README、issue、PR 或 Actions 日志。
