## GitHub 交接

新增工作位于现有开发分支。需要核对远端提交确实存在，不能只看本机 commit。若默认分支仍是旧版本，应通过明确的 PR 和维护者确认完成合入／默认分支切换；本轮不擅自覆盖默认分支。

CI 文件加入仓库不等于 GitHub 已经成功运行它。已知依赖问题未解决前，安全门禁预期会失败；真实模型、微信工具和共享生产探针也不在无密钥的 GitHub hosted runner 上自动执行。

正式交付需由维护者确认：远端版本、分支和发布标签、模型和字体来源、私下联系方式、运维权限、备份位置、告警接收人、未关闭风险及后续责任人。密钥通过私密渠道交接，不写进 README、issue 或 Actions 日志。
