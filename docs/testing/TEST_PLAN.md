# 测试方案与执行方法

版本：2026-10-20。目标是验证微信小程序的功能、输出效果、等待时间、资源占用和安全边界。**构建通过、接口通过、微信模拟器通过、真机通过是四种不同结论。**

## 测试分层

1. 纯前端检查：缓存、账号切换、编辑参数、幂等、取消、超时、GIF 编码及队列恢复。
2. 后端隔离测试：每次使用临时数据库，覆盖权限、输入限制、推荐、模板、队列和回收。外部微信服务使用模拟结果，不能据此声明真实微信审核通过。
3. 微信 production 产物：在微信开发者工具中正常导入，检查所有页面初始化、实际接口加载、导航和运行异常；记录微信性能 API 条目。
4. 真实服务器小样本：独立测试账号与合成素材，真实模型、worker、FFmpeg，串行提交耗时任务。
5. 全模板冒烟：在开发工作机上，每个内置模板使用一组声明允许的输入，检查能否解码、尺寸、帧数、文件大小和渲染耗时。
6. 真机及效果验收：iPhone／Android、不同微信版本、弱网、系统后台、权限拒绝和真实照片。没有实体设备时明确标为待测。
7. 安全与运维：权限隔离、输入大小、限速、依赖公告、主机隔离、磁盘与流量、备份副本完整性。未知主机完整性不能靠应用测试消除。

## 功能覆盖清单

每项都需要同时记录成功路径、失败路径、效果和等待时间。以下编号用于测试报告与问题追踪。

### F01 首页、分类、人气和分页

- 使用全部／文字／图片／混合分类，翻到首尾页，切换人气和时间排序。
- 名称、输入要求、数量和翻页结果与接口一致；空列表有说明；断网能重试。
- 人气变化只依据实际事件；重复曝光、重复回执不得重复计数。
- 记录首次可操作、接口返回、九张缩略图可见的时间与下载字节。
- 冷启动、缓存启动、重新登录分别记录，不能混算。

### F02 模板详情、收藏、历史

- 打开不同输入类型模板；游客收藏／浏览后登录，验证合并和重复去除。
- 收藏与历史各 100 条边界；取消收藏、清空历史、从记录再次打开模板。
- A／B 账号互不覆盖，过期会话显示正确提示。
- 记录缓存打开与联网打开耗时；不把后台同步时长算成用户必须等待的时长。

### F03 手动生成静态图、GIF 和多图

- 覆盖零图文字、单图、双图、图片加文字、透明图、动画输入和中文。
- 分别检查模板声明的最少、最多、少于要求、超出要求与空白文字。
- 动画模板结果必须真实多帧，内容类型正确；静态模板须能正确解码。
- 检查输出体积、尺寸、帧数、中文可读性；真机验证保存、预览和添加微信表情。
- 缓存命中与首次生成分开计时。随机模板不能用重复内容凑“不同效果”。

### F04 图片编辑与去背景

- 裁剪、原比例／预设比例、旋转、翻转、多图切换、四步撤销和还原。
- 棋盘格透明预览，取消后原图仍在；迟到响应不能覆盖新照片或新账号。
- 本机画布输出与后端输入方向、比例一致。
- 去背景分别测试清晰单人、猫狗、物体、多主体、复杂背景、透明图；准备人工标注蒙版，统计边缘误删和漏删。
- 记录本机编辑响应、模型冷／热耗时、内存和上传量。当前生产小样本不是分割准确率基准。

### F05 主体检测和框选

- 双人样例至少出现两个候选；候选越界应裁回图内；可选择第二个人并手动调整。
- 没识别到对象、设备接口不可用、取消、超时均能手动框选。
- 确认区域后，换批不能再次自动选择别的脸。
- 人物、侧脸、猫及其他动物分开统计候选命中率；只测双人正脸不能代表所有场景。

### F06 AI 九张、换批、动画和选择

- 首批、换批、重新上传同图、历史恢复、失败模板补位。
- 可用模板充分时每批九个不同 key，相邻批次无重复；不足时准确说明数量。
- GIF 原图与缩略图均需多帧且时长一致；放大、分享取完整结果。
- 多选／全选／取消、保存一半失败后继续、关闭个性化。
- 检查账号一次活动任务、全局队列上限、分钟／小时频率及幂等重试。
- 记录预处理、队列等待、生成、九张预览加载及完整下载耗时，不只记录任务创建响应。

### F07 视频选段、裁剪和文字

- 1 秒、3 秒、9 秒，以及超过 9 秒的视频；竖屏、横屏、HEVC／H.264 和方向信息。
- 原生时间轴选段、页面内再次改段、进度拖动、后续帧预览。
- 自由框选、旋转、翻转、文字拖动、字号、粗细、颜色、背景、键盘遮挡。
- 输出必须保留所选完整时长，长边 ≤240 px、大小 ≤512,000 字节。
- 两类场景：平缓画面与高运动／高纹理画面；记录帧数和帧率下降，人工观看是否可接受。
- Live 原图没有上传入口，提示先在本地相册转存视频。

### F08 本机 GIF、回退与队列

- 设备支持时本机生成；不支持、压缩超时、解码异常时切换后台。
- 等待完成直接展示；收起后队列能领取，不自动跳走。
- 离开页面、切换账号、断网重试、成品同步超时、系统结束进程分别测试。
- 本机成品重试同步必须幂等且字节不变；不得将旧账号结果同步到新账号。
- 真机验证低内存与后台行为；模拟器不能代替系统调度测试。

### F09 手动创作、私藏与发布

- 添加背景、图槽和文字，移动、调整尺寸、颜色、名字，私藏后制作。
- 非法图层、越界、超长文字、未确认版权、陌生账号访问全部拒绝。
- 私有背景不能通过公共素材地址读取。
- 文本审核拒绝、图片审核拒绝、服务超时均不得公开。
- 正向发布需要真实开发者账号及已授权测试素材；本轮不向公共仓库发布测试垃圾模板。

### F10 AI 识图制模

- 边缘横排文字、无字图、倾斜字、多段文字、动画及复杂遮挡。
- 使用真实 OCR 检查识别文字和置信度；合成替换后保护区像素应保持。
- 低置信度只可成为有保护区与回放校验的私有草稿；保存校对后必须检查对应预览再确认，不能绕过内容检查公开。
- 每日成功额度、每小时三次尝试、并发、重试、失败退回成功额度分别记录。
- 真实 OCR 成功、外部内容审核通过与进入公共模板库必须分成三项验收。

### F11 账号、资料与隐私

- 真实 wx.login、重复登录、网络失败、会话过期和撤销。
- 修改昵称、头像归一化；头像权限拒绝和无头像情况。
- 私有接口无 token 返回 401，其他账号访问返回 404 或拒绝。
- 覆盖删除、注销、撤回和举报接口，校验所有权、活动任务拒绝、会话失效、迟到写入拒绝、清理重试与保留摘要；另外进行真机确认流程验收。

### F12 队列通知、重做、删除与恢复

- 完成后未读数变化，查看后消除；不能删除仍在运行的任务。
- 重做使用原素材；过期素材提示重新选择。
- 本地测试模拟 worker 租约过期、异常、退款、重启恢复；共享生产机不为了测试故意停止 worker。
- 七天过期、24 小时素材清理和 90 天反馈边界用隔离时钟测试。

### F13 采集和模板质量

- 许可白名单、地址白名单、重定向、超时、体积预算、重复图片／文字意图、低置信度待处理。
- 采集失败不影响基础制作；后台模板版本能追溯来源和许可。
- 外网来源的连续成功、定时任务跨日执行仍需长周期观测，本轮不宣称覆盖全网热点。

### F14 运维、安全与资源

- 只读主机状态、监听端口、服务用户、资源限制与密钥文件权限。
- 小体积错误请求验证限速、413、422、401／404；不发送漏洞利用载荷。
- 数据库在线备份后在私有临时副本做完整性检查；完整图片＋数据库恢复另外验收。
- 分开计算 API、worker、主页、OpenClaw 和加密／代理开销，不能把网卡累计或 Nginx 字节当作云账单。

## 性能方法和目标

以下是建议验收目标，不是已经承诺的服务等级：

- 健康接口：源站正常负载 P95 <100 ms；分类元数据 <200 ms。
- 常见手动模板：首次生成通常 <2 s，热缓存单独统计；重型动画另设预算。
- 九张推荐：热模型、没有前序排队时，建议完整结果 <15 s。
- 9 秒视频：建议服务器转换 <10 s，上传另计；同时检验体积和帧率。
- 真机首页：Wi-Fi 首次可用建议 <3 s，弱网目标和失败提示另验收。
- 每个稳定性能结论至少 20 次；P95、错误率及容量规划使用更大样本并写明网络、硬件、输入和并发。两个成功样本只能作小样本观测。

本轮共享生产机只做最多两个并发的廉价读取，昂贵任务串行；不测最大 QPS。不重启模型制造冷启动，也不故意制造 OOM、磁盘满、断电或服务故障。

后续在隔离预发布环境做 1／2／4／8 并发分级测试，每档持续一分钟，记录 P50／P95、吞吐、错误、等待、RSS、CPU、磁盘和流量。先确认非恶意正常负载，再评估保护策略。共享机器不得直接照搬这个并发梯度。

生产探针在提交新任务前检查可用内存、系统负载和磁盘空闲；低于 3 GiB 内存、负载高于 3.5 或磁盘低于 10 GiB 时停止新增任务，已经接受的任务等待完成后清理。不要通过伪造访客 IP 绕过真实限速。

## 重现命令

```sh
.venv/bin/python tools/qa/run_local.py --build --output artifacts/local.json
.venv/bin/python tools/qa/catalog_smoke.py --output artifacts/catalog.json
.venv/bin/python tools/qa/repo_checks.py --output artifacts/repo-checks.json
.venv/bin/python tools/qa/npm_advisories.py --production --output artifacts/npm-production.json
cd frontend
npm run test:mp-weixin -- --output-dir /tmp/gensticker-weixin-check
```

catalog 冒烟保留每个失败并返回非零；“可选名字”问题不应通过自动补字掩盖。独立重跑时可使用 `--key KEY --fill-optional` 进行归因。

微信自动化截图接口在长时间重复测试后可能遇到模拟器 `saveFile` 配额。可以显式使用 `--screenshots off` 只执行渲染检查，报告会记录没有新截图；不能删除用户文件来让测试变绿。

`live_probe.py --allow-fixtures` 会在指定服务器创建合成账号并写入测试任务，必须明确设置正确状态目录、确认授权及无其他活动任务。它不是可以放进公共 CI 的无副作用测试；测试结束会清理私有测试数据，少量真实生成统计仍可能计入热度。

## 真机待验收记录

至少包括一台较新 iPhone、一台内存较低的 iPhone、一台主流 Android 和一台较旧 Android；写明具体型号、系统、微信版本、基础库、网络、样例和实测时间。

每台完成相册授权／拒绝、Live 转存视频、长视频选段、文字拖动及键盘、动图预览、保存、普通小程序分享、聊天工具入口、弱网、切后台、系统结束、再次进入、低存储与换账号。没有设备或真实微信账号权限时记录“待测”，不能填“通过”。
