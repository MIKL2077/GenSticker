# CPU 人物融合交付与实测（2026-10-27）

已在现有服务器部署 `cpu-character-v1`。这是接近用户选定 C 的结构性融合方案：人物五官清楚可见，同时保留模板头部外形、毛发边缘、耳朵、动作和道具。C 本身是生成模型重绘的离线示意，不能当作服务器实测结果。本次没有声称传统方法能达到 C 同等的细节、表情生成或所有照片上的视觉质量。

## 方案与环境

- 4 vCPU、16 GB、无 GPU；现有 GenSticker 服务共享 200% CPU / 4 GiB，API 与 worker 各有 2 GiB 限制。没有升级服务器。
- 使用约 3.58 MiB 的 [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) 做五官定位；不是大模型，不需要 PyTorch、完整 TensorFlow 或外部图片 API。模型只输出几何，不做身份识别。
- 权重固定 URL 与 SHA-256；安装时下载，生成时禁止下载。模型卡/来源见 `deploy/model-licenses/face-landmarker-v1.md`。
- 上传图片按一次渲染准备一次；一段 GIF、一次九图任务复用定位和人物遮罩。模板几何、原五官清理、固定前景遮罩在作者阶段完成，运行时不对原 GIF 逐帧检测。
- OpenCV 三角形形变、局部光色匹配、拉普拉斯金字塔融合；人物下巴边界排除衣领，猫模板把头发放在两耳之间。最后再按模板遮罩恢复全部固定像素。
- 黑白熊猫模板使用显式的黑白处理；真人场景保留原发型、衣服。无可定位人脸或任意物体输入回退到各模板的有限头像槽，不强制用户使用人脸检测或抠图。
- 中间帧直接在内存中交接，省去每帧 PNG 编解码；边缘颜色用最近有效像素延展，减少黑边和多余的运行时修补。

无法实现的部分：没有生成模型时，不能可靠补出未拍到的侧脸、发丝、牙齿，或让一张中性照片获得原模板的张嘴、哭笑等新表情。侧脸、遮挡、极小头像、夸张卡通五官不套通用融合。输入提示明确表情来自上传照片。

## 模板检查

本次快照共有 958 个已发布模板，每个 key、原版本、源码/原图或配方摘要及处理理由均记录在 [`20261027-compositing.json`](../template-audit/20261027-compositing.json)。

- 44 个启用人物融合，其中 14 个 GIF，共 278 个源帧。
- 438 个继续使用贴图、头像道具或原有图像特效。
- 476 个无用户照片槽，继续使用文字适配器。

482 个带图模板检查了原图及关键帧。对融合候选额外生成真实私有照片输出，逐个筛选；已启用的 GIF 复核全部帧。未发布的试图包括：蘑菇头小脸裁断五官、红包遮挡导致旧眉毛残留、泪线与轮廓相连、转头拉伸、极小舞台人脸、首帧固定区检查不通过等。定位成功不等于通过视觉验收。

保持原 key，新配方增加版本。揉脸猫为 v4。用户照片和融合验证图不在 Git、不在公开模板资源包中；公开包只有原有素材衍生的模板资产、遮罩及配方。未将 attribution 当作原素材版权验证。

## CPU 速度

在真实主机另设 200% CPU / 1 GiB 的测试单元，每项独立运行 12 次，无结果缓存。以下为渲染耗时，未计公网、排队或主体提取；小样本 P95 使用最近秩统计，不是服务 SLA。

- 揉脸猫：14 帧 / 1400 ms 循环，P50 **478.3 ms**，P95 **512.9 ms**，113880 bytes。
- 摆手猫：22 帧 / 1760 ms，P50 **717.4 ms**，P95 **761.8 ms**，164284 bytes。
- 熊猫期待：24 帧 / 4360 ms，P50 **611.7 ms**，P95 **644.8 ms**。
- 饮茶哥：24 帧 / 3000 ms，P50 **992.7 ms**，P95 **1012.6 ms**。
- 王冰冰挥手：22 帧 / 2200 ms，P50 **767.7 ms**，P95 **792.5 ms**。
- 静图样本 P50 **39.0–175.4 ms**；模型初始化约 **0.574 s**，由服务启动预热承担。
- 独立测试进程最大 RSS 269548 KiB；上线后 API / worker 各约 460 MiB，位于原资源限制内。

完整私有实测记录位于本机 `artifacts/cpu-fusion-20261027/server-benchmark.json`。本次验证照片来自用户给出的低分辨率截图裁片；传统算法不会补回丢失的图像细节。
