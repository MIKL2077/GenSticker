# 模板编辑与去背景提速

2026-10-20。模板详情中的图片编辑改为直接使用 AI 生图的 `SubjectPicker`：检测候选主角、点选或手动框选、拖动及调整范围、明确确认后回填图片。模板编辑保留多图切换、左右翻转、旋转、去背景、独立撤销和还原上传图。操作已有选框时先处理该区域；处理失败保留当前图。确认使用 PNG，避免把透明背景重新压成 JPEG；确认结果直接接收，不再裁剪第二次。

`TemplateImageEditor` 负责模板编辑扩展工具，和 AI 生图共用主体框选实现。旧的模板参照生成及下载不再阻塞此入口。自制模板页面的通用背景编辑器继续保留，底层去背景服务同样受益。

去背景依次尝试复用现有透明通道、微信本机 ONNX 推理、服务器回退。模型为现有 U2NetP（4,574,861 字节），按固定摘要校验并保存在微信文件缓存，进入编辑器时异步准备，模型会话闲置 90 秒后释放。照片和遮罩不写入模型缓存。使用原始 320 × 320 归一化及输出张量，设备不支持、加载或推理超时、输出不明确时回退；本机推理错误短期退避，避免每次重试都等待失败。透明图不需要加载模型或上传照片。

回退服务器前将画布长边限制在 1280 px，普通不透明照片使用 JPEG 上传，透明输入保留 PNG。一次请求直接返回透明 PNG，省去之前领取 URL 后的第二次下载；文件写入仍使用额度清理与重试。账号切换后不再上传或接收旧账号的图片。原有 URL 交付接口继续兼容已有客户端。

后端启动时预热模型，去掉无用的 OpenCV 首次导入；同身份同图请求共享一次提取，缓存访问加锁。模型下载端点只提供固定摘要且已校验的公共模型文件，用户图片接口仍为私有且禁止公共缓存。未调整共享服务器资源上限。

## 验证

19 组前端回归、96 项后端测试、微信与 H5 构建通过。最后移除无用导入后，9 项主体与模型测试再次通过。

微信生产构建的七个页面启动通过。原生交互使用打包的公开图标模拟选图，实际操作主体框选、翻转、旋转、透明图去背景、撤销、还原与 PNG 确认回填，全部通过；仅选图入口使用固定测试素材。检查期间保持微信域名校验开启。模拟器不用于宣称实体手机上的 ONNX/NPU 兼容性或速度；实体设备尚需验收，首次模型下载和低端机可能回退服务器。

线上使用公开图标构造 1280 px 不透明输入，三次独立身份的实际推理请求耗时 0.563–0.677 秒，同图缓存请求 0.0060–0.0065 秒。该数据来自服务器本机 HTTP，包含解码、推理、PNG 导出与本机交付，不包含手机网络，也不是修改前后的手机速度对比。模型文件长度与 SHA256、公共模型缓存、私有结果隔离、旧 URL 交付及服务状态均通过。

证据见 [template-editor](evidence/2026-10-20/template-editor/)。应用文件已备份，仅更新并重启小程序 API 和 worker。没有推送 GitHub 或正式发布微信小程序。
