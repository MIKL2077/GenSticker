# 图片编辑与本机去背景验收

日期：2026-10-21。目标：微信小程序。对应修改为本报告所在提交；测试在提交前的工作区执行。

## 原因与修改

1. **竖图压扁**：微信 `getImageInfo` 返回不考虑 EXIF 旋转的原始尺寸，图片显示和 Canvas 解码已转正。此前按原始横图尺寸搭建预览、压缩大图、绘制去背景输入，造成拉伸。现在共用旋转后的显示尺寸计算预览和压缩参数，预览使用 `aspectFit`，去背景画布依据实际解码尺寸。
2. **自动选人缺失**：原流程在本机人脸检测不可用且未登录时直接返回手动模式。现在游客也可使用限流的服务器瞬时检测；模拟器跳过不支持的旧人脸接口，真机仍可优先本机检测。服务器补充较小人脸检测，以及没有明确人脸时的真实前景区域候选。前景候选标为“主体”，不假装确认识别到了人物；始终可手动框选或重新识别。
3. **去背景失败难以定位**：微信回调经常抛出 `{errMsg}`，原界面只读 `message`；二进制错误响应中的服务器提示也被丢掉。现在分别显示网络、读取、忙碌和图片问题，保留原图。微信回退使用 `uploadFile` 上传文件、随机私有结果地址和 `downloadFile` 下载透明 PNG，避免大块 ArrayBuffer 请求响应。下载显示进度，有明确超时和迟到文件清理；可以关闭处理窗口，旧结果不会修改新编辑。

`stopFaceDetect` 是旧接口弃用警告，截图中的分类超时属于网络请求失败；不能把二者合并解释成同一个抠图错误。源站健康和图片处理正常，但本次微信公网链路明显慢，仍不能承诺回退数秒完成。

## 本机去背景

兼容真机使用微信 `createInferenceSession` 与已固定校验值的 U2NetP 模型。首次后台下载 4,574,861 字节模型，缓存成功后复用；只下载模型，不随模型请求上传照片。加载先尝试 NPU，加载失败后再关闭 NPU 重试。输入缩放至 320×320，处理后恢复透明蒙版；已有透明图片可直接复用。

首次模型下载允许在后台继续等待，编辑器显示准备中、已就绪或需要服务器处理的状态。模型就绪不等于所有算子都必然兼容；运行失败、超时或设备不支持时仍有服务器回退。微信开发者工具明确不运行本机推理。当前没有实体手机可控制，**本机真实模型的速度、内存和设备兼容性仍待真机验收**，单元测试不代替这一项。

建议在至少一台 iPhone 和一台 Android 测试首次下载、缓存后重进、断网去背景、遮挡人脸、多人、低内存和连续换图。验证本机成功时没有 `/images/subject-file` 或 `/images/subject` 照片请求；本机成功不占服务器推理资源。

## 已执行的测试

- 20 组前端测试、6 项账号测试、95 项后端功能测试，以及微信/H5 构建通过，见[回归记录](evidence/2026-10-21/image-editor/regression.json)。覆盖旋转尺寸、原图保留、游客检测、取消后的新旧操作隔离、模型缓存与 NPU 加载回退、请求失败提示、私有下载地址校验及迟到文件清理。
- 原生 API：800×480、EXIF 为右旋的照片，翻转输出 480×800；2400×1440、同样右旋的大图，压缩和翻转输出 768×1280。完整竖图比例保持 0.6。
- 原生透明图复用：120×180 测试图在本机复用透明通道，输出 81×121，无需服务器处理。该路径不是实体手机模型推理性能。
- 真实游客检测：使用 OpenCV 公开样例组成的双人脸测试图，接口返回两个真实候选。没有使用用户截图中的私人照片。
- 真实服务器去背景：微信原生上传和下载得到透明 PNG，alpha 最小为 0、最大为 255。本次完整链路约 40.9 秒；同类源站处理约 0.4～0.6 秒。这是小样本和当前网络观察，不是容量或所有用户耗时结论。

[微信原生记录](evidence/2026-10-21/image-editor/native.json)记录图像处理和界面验收。原生点击已验证翻转后切换第二人、回到原图坐标、确认并关闭同一弹层；确认按钮底边约 773 px，视口为 850 px。比例截图见[原生预览](evidence/2026-10-21/image-editor/upright.png)。模型检测使用公开照片，界面比例及点击使用合成几何图，二者分开验证，不能用模拟候选证明模型准确率。

## 资源与安全

服务器仍沿用共享主机的 CPU、内存和流量预算，没有为了抠图提高资源上限。`/images/subject-file` 上传上限为 8 MiB，Nginx 请求体上限为 9 MiB，并使用每 IP 每分钟 6 次、突发 3 次的生成限流。接口进入既有双请求接纳和双处理槽，流量预算接近上限时暂停新处理。前景候选模型回退同一时刻只接纳一次。

结果地址绑定账号或游客标识，其他身份返回 404；前端只允许下载当前 API 下固定格式的结果路径，不把登录信息发往任意地址。图片处理缓存和结果票据留在有时限与体积限制的内存中，图片检测不新建素材。失败和取消均保留上传原图。部署前校验旧代码、备份修改文件和 Nginx 配置，检查失败自动回退，主页与 OpenClaw 健康检查正常，见[线上核对](evidence/2026-10-21/image-editor/server.json)。

## 验收重点

重新编译或扫描本次预览码。检查相册横图、竖图、带旋转标记的大图，确认人物比例和框选位置一致；尝试选人后翻转、换人、撤销、关闭处理中窗口后重新选图。真机等待本机模型就绪后断网测试，再恢复网络验证不支持时的回退。弱网回退仍可能较慢，应以进度、可取消和失败保留原图为最低要求，不宣称已经消除公网延迟。
