# 数据与隐私说明（开发交接版）

这份文件用于说明代码当前做什么，不替代正式的用户隐私政策。上线时必须填写真实运营者、联系方式、用途、第三方服务、删除渠道和备份规则，并在微信后台完成对应配置。

## 处理的数据

- 微信登录：临时登录 code 发给后端，由后端与微信换取身份；AppSecret 不下发小程序。
- 会话：客户端保存登录 token；服务端保存 token 哈希与有效期，默认七天。
- 资料：用户主动提交昵称和头像；头像会归一化保存。不是自动读取微信头像。
- 用户库：收藏、浏览历史和同步操作，账号间隔离。
- 图片编辑：兼容手机优先在本机去背景，约 4.6 MB 模型经校验后缓存在本机，不包含用户照片。本机不支持、超时或处理失败时会回退自己的服务器；编辑窗口会提示本机是否就绪。
- 主体检测：游客和登录用户均可使用，只返回候选坐标，不创建照片素材。上传链路可能产生由框架清理的短期临时文件，不作为素材长期保留。确认区域后才用于后续模板生成。
- 去背景回退：通过微信文件上传发送选定区域，结果使用绑定账号或游客标识的随机地址领取。服务器图片处理缓存有体积和时限限制；客户端关闭编辑后拒绝迟到结果，并释放本机临时导出。
- 视频：兼容时本机处理；后台回退会上传压缩后的视频，生成结果可跨设备同步。
- 模板：私有模板需要归属校验；用户明确申请发布后才进入内容检查。
- 偏好与热度：记录有限的曝光、选择、保存和生成事件，用于推荐与去重；不保存人脸身份向量。

## 外部服务

模型主要在自己的服务器 CPU 上运行，不调用付费图片生成 API。但微信登录和公开模板的内容检查会访问微信官方接口，公开模板检查涉及必要的文本、图片、头像或渲染样例。当前实现还使用 Cloudflare Tunnel；网络服务处理范围应在正式政策中说明。

不要对用户宣传“所有图片绝不经过任何第三方”，也不要将“非付费 AI”混同于没有外部接口。

## 保留时间

推荐原图和处理缓存通常 24 小时，任务与结果通常七天，反馈最长 90 天；清理由后台周期任务执行，不是到秒即刻消失。视频源素材通常七天。

账号、头像、收藏、私有模板和被引用模板素材不自动套用七天期限。用户可在“我的 → 管理素材与账号”删除视频／模板、撤回公开模板或注销账号。注销覆盖当前在线资料、会话、收藏、历史、私有作品、处理缓存、回放、偏好与反馈；制作中的任务须先完成。删除中断会由后台重试。防滥用的上传摘要和删除标记保留约 31 天，注销重登不能重置当日预算。

下载到相册、他人设备的副本无法撤回。加密备份采用独立保留规则；本地每日加密备份最多保留最近 7 份成功归档，旧的离机快照有独立规则；运营者尚需确定离机保留期、持续传输与到期删除流程，不能承诺注销立即清除历史备份。

## 控制与待验收事项

登录使用微信原生隐私授权能力（可用时调用 `wx.requirePrivacyAuthorize`），页面提供隐私指引入口；隐私 API 的实际授权弹窗、拒绝后的路径和后台用途配置仍须用真实账号验收，不把模拟结果当作批准。

模板详情提供举报原因入口；维护者使用本机下架工具核查处理。待补齐真实运营者、私下联系人、处理时限、素材权利提示及完整的正式政策。照片中的视觉表情分析不代表真实心理状态。

[微信官方隐私授权文档](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)应在提交审核前重新核对。
